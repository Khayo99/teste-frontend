# Quickstart: NFT Marketplace Home

Install dependencies with `npm install`, start mocks with `npm run dev`, then open the home route.

1. Confirm the header, hero, filters, order control and catalog cards match the desktop Figma frame.
2. Filter by collection and network, apply a price range and confirm compatible cards remain.
3. Change sort order and confirm cards reorder without losing filters.
4. Search for a card, reload the route and confirm the address restores the search.
5. Run `npm run typecheck`, `npm run lint`, `npm run build` and `npm run test:e2e`.
