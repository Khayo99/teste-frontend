# Quickstart: Marketplace Footer

1. Run `npm run dev`.
2. Open the home page and scroll to the final section.
3. At 1440 px, verify three assurance cards, newsletter field, brand band, four link groups and copyright line.
4. Submit `colecionador@example.com` and confirm the success feedback.
5. Submit an invalid e-mail and confirm the field exposes validation feedback.
6. Verify all footer controls are reachable with `Tab` at 390 px, 768 px and 1440 px.
7. Run `npm run typecheck`, `npm run lint`, `npm run build`, and `npm run test:e2e -- e2e/footer.spec.ts`.
